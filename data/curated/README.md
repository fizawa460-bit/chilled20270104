# Curated parenting corpus

Only records explicitly judged to be about the author's own parenting/family childcare should be placed here.

Suggested fields:
- `statusId`
- `postedAt`
- `text`
- `url`
- `matchedKeywords`
- `parentingRelevant: true`
- `categories` such as `sleep`, `illness`, `feeding`, `daycare`, `work_balance`, `development`, `education`, `play`, `parenting_values`

The normalized candidate set is intentionally not auto-promoted here, because broad keywords such as `子供` also return unrelated childhood anecdotes and general discussion.
